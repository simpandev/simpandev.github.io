# Audio Files

Place your museum audio guide files in this directory.

## Required Files

The following audio files are expected by the application:

- `entrance.mp3` - Welcome to the Museum (Entrance Hall)
- `ancient-art.mp3` - Ancient Art Gallery guide
- `sculpture.mp3` - Sculpture Hall guide  
- `modern-art.mp3` - Modern Art Gallery guide
- `special-exhibition.mp3` - Special Exhibition guide

## Supported Formats

The HTML5 audio element supports:
- MP3 (recommended for best browser compatibility)
- WAV
- OGG

## Notes

- Keep audio files reasonably sized for web delivery
- Consider providing transcripts for accessibility
